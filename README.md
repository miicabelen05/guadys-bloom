# Guady´s Bloom

## Descripción
Guady´s Bloom es un proyecto personal web desarrollado como segunda pre entrega del curso de Desarrollo Web.  
El sitio está compuesto por múltiples páginas HTML, maquetadas con CSS propio, utilizando box model, Flexbox y Grid para la vista desktop, con adaptación responsive para dispositivos móviles.

## Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- Grid
- Bootstrap

## Estructura del proyecto
- `index.html`
- `/pages`
    - `productos.html`
    - `contacto.html`
- `/css`
    - `estilos.css`
- `/img`
    - fondo.jpg
    - imagen1.jpg
    - imagen2.jpg
    - imagen3.jpg
    - logo.jpg
- `/video`
    - El video de representación esta externo (Google Drive)

## Responsive
El proyecto contempla adaptación responsive para vista mobile en al menos dos páginas mediante media queries y/o sistema de grillas.

## Bootstrap
El proyecto incorpora componentes de Bootstrap respetando la consigna de no usarlo para el maquetado general, delegando la estructura principal al CSS propio.
